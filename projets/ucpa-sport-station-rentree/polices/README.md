# Polices du projet

`Montserrat-Bold.ttf` — distribuée sous licence SIL Open Font License 1.1
(voir `OFL.txt`), depuis le dépôt officiel du projet Montserrat.

La police est versionnée avec le montage pour que le rendu soit reproductible
sur une machine où elle n'est pas installée : `style.dossier_polices: polices`
dans `montage-v3.yaml` la donne directement à ffmpeg, sans installation
système.
